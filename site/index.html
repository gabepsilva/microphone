04 — install
Two lines
# CPython 3.12, uv, PipeWire on Linux
$ uv sync --locked --all-groups
$ uv run tagalong
Optional tagalong.yaml remembers mic, meeting app, speech engine, model, and policy between runs. Without it, Piper speaks, both voice sources are listened for, and no meeting app is selected yet.

Needs an authenticated codex CLI. First run pulls the speech models once. Far-end capture also wants PipeWire (pw-record, pw-link, pw-dump), pactl, and ffmpeg/ffplay.

keys, mid-session
^Pcycle who Taga answers ^Kmute the microphone ^Ttoggle spoken replies ^Xinterrupt Taga ^Btoggle sidebar ^Ssave transcript /command palette

03 — read this part
It records people. Tell them.

Transcribing the other side of a call is regulated in plenty of places and impolite everywhere else. Say so before the first turn.

→Transcripts stay on disk, yours to delete.
→Remote speech is untrusted context. It cannot issue instructions or run commands.
→Every command Taga runs is printed with its exit code.
