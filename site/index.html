04 — install
Two lines
# pipewire on linux, blackhole on macos
$ pipx install voice-codex
$ voice-codex
The wizard picks devices, builds the meeting sink, writes ~/.voice-codex.yaml, and tears it all down on exit.
Needs an authenticated codex CLI and Python 3.11+. First run pulls the speech model once, then never phones home.

03 — read this part
It records people. Tell them.
Transcribing the other side of a call is regulated in plenty of places and impolite everywhere else. voice-codex prints a consent reminder before the first turn.
→Transcripts stay on disk, yours to delete.
→Remote speech is untrusted context. It can never issue instructions or run commands.
→Every command Codex runs is printed with its exit code.
